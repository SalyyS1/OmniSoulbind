Items that are yours — kept on death, useless to thieves.

OmniSoulbind stamps an item to a player's soul. Soulbound gear survives death, refuses to be picked up or used by anyone else, and carries a clean owner lore line. The binding lives entirely in the item's NBT — no database, no bloat, full Folia support.

What it does

Keep on death

A dying player's own soulbound items are pulled from the drop pile and handed back on respawn (or instantly, your call). Overflow drops safely at their feet.

Anti-theft pickup

Other players — and non-player entities — cannot pick up soulbound gear they don't own. Dropped loot stays untouchable to strangers.

Use restriction

Clicking or interacting with someone else's soulbound item is cancelled with a message. No borrowing, no stealing.

MMOItems-aware auto-bind

Auto-bind on pickup by MMOItems tier or a vanilla material list. Manual binding is always one command away.

NBT-native, DB-free

Owner UUID + name live in the item's PersistentDataContainer. Nothing to migrate, nothing to corrupt (KISS).

Non-destructive lore

A configurable "Soulbound to %owner%" lore line is appended without wiping existing lore, and never duplicated on re-scan.

Installation

  1. Drop OmniSoulbind-x.y.z.jar into your server's plugins/ folder.
  2. Start the server once to generate plugins/OmniSoulbind/config.yml.
  3. Tune your toggles, then run /soulbind reload.

Optional soft dependencies

  • MMOItems — enables tier-based auto-bind (reads the item's stored tier).
  • PlaceholderAPI — enables %omnisoulbind_owner% and %omnisoulbind_bound%.

Commands & permissions

Alias: /sb. omnisoulbind.use defaults to true; omnisoulbind.admin defaults to op.

Configuration

Every field is optional and falls back to a sensible default.

# Keep a player's own soulbound items instead of dropping them on death.
keep-on-death: true
# true  = hand items back on respawn
# false = re-add immediately after the death event
return-on-respawn: true

# Stop other players (and mobs) from picking up items they don't own.
restrict-pickup: true
# Stop other players from clicking / interacting with items bound to someone else.
restrict-use: true

# Automatically bind matching items when a player picks them up.
auto-bind:
  enabled: false
  # MMOItems tiers that trigger auto-bind (case-insensitive).
  tiers:
    - LEGENDARY
    - MYTHICAL
  # Vanilla materials that trigger auto-bind.
  materials:
    - NETHERITE_SWORD
    - ELYTRA

# Lore line appended to a bound item. %owner% = owner name.
lore-line: "&7Soulbound to &e%owner%"

messages:
  bound: "&aBound this item to your soul."
  already-bound: "&eThis item is already soulbound to &e%owner%&e."
  no-item: "&cHold an item to soulbind it."
  unbound: "&aRemoved the soulbinding from this item."
  not-bound: "&7This item is not soulbound."
  reloaded: "&aOmniSoulbind reloaded."
  info: "&7Soulbound to &e%owner%&7."
  use-denied: "&cThis item is soulbound to &e%owner%&c."
